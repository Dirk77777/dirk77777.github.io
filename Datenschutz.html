Zweck

„Salt Road Atlas Stats“ ist ein privates Werkzeug ausschließlich für den Betreiber des YouTube-Kanals „Salt Road Atlas“. Es ruft über die YouTube Data API und die YouTube Analytics API Statistiken der eigenen Videos ab (z. B. Aufrufe, Likes, Kommentare, Zugriffsquellen, Wiedergabedauer) und erstellt daraus eine tägliche Übersicht.

Welche Daten verarbeitet werden

Es werden nur Kanal- und Videostatistiken des eigenen Kanals mit Lesezugriff abgerufen (Berechtigungen youtube.readonly und yt-analytics.readonly). Es werden keine personenbezogenen Daten von Zuschauern gespeichert, und es werden keine Daten an Dritte weitergegeben oder verkauft.

Speicherung

Die abgerufenen Statistiken werden nur zur Erstellung der Berichte gespeichert. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Google API Services User Data Policy

Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
